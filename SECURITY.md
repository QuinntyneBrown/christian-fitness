# Security Policy

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions
or pull requests.**

Report them privately through
[GitHub private vulnerability reporting](https://github.com/QuinntyneBrown/christian-fitness/security/advisories/new).

Please include as much of the following as you can:

- The type of issue (for example authorization bypass, cross-site scripting, data exposure)
- The affected files, endpoints or screens
- Steps to reproduce, and proof-of-concept code if available
- The impact, including how an attacker might exploit it

You should receive an acknowledgement within 5 business days. We will keep you informed of
progress toward a fix and disclosure.

## Supported versions

Only the latest commit on `main` receives security fixes.

## Personal data

This application handles personal and sensitive data (contact details, messages, and
optional faith details). Reports involving exposure of such data are treated as the highest
priority.
