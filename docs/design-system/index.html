How to use

  1. Link tokens/tokens.css once as a global foundation; it self-hosts the fonts.
  2. Use the BEM blocks from assets/components.css; in Angular each component's encapsulated stylesheet keeps the block name and reads tokens by role.
  3. States assistive technology needs are attributes (aria-current, aria-pressed, aria-invalid, aria-busy, disabled); style through them.
  4. Generate platform constants from tokens/tokens.json (DTCG).
  5. Change the system in tools/ and tokens/, then run python3 docs/design-system/tools/build.py and the checkers (see README).
