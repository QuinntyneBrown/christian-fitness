Overview

Colour comes from the prototype: ink text on a warm canvas, bordeaux for the one thing to do, borealis blue as the second brand colour on bordeaux and ink panels, and blush for selected and confirmed states. Neutrals are a warm stone ramp, never pure grey. Errors use bordeaux too (the prototype's choice), always with an icon and words so colour is never the only signal.

Components read semantic tokens (--color-*) only. Primitives (--palette-*) exist to be referenced by semantic tokens and by nothing else.

Primitive ramps

Primitive ramps. Step numbers rise with darkness; 700 bordeaux, 800 bordeaux-deep, 50 blush, 300 borealis, 50 canvas, 200 line and 950 ink are the prototype's own values.

Usage

  • One accent per view: bordeaux marks the primary action, the current place and counts that need attention. Do not use it for decoration.
  • Brand panels (--color-bg-brand) take white text, borealis highlights and the borealis focus ring; the same holds on admin chrome.
  • Text on canvas, surface and raised surfaces uses --color-fg-default, -muted or -subtle; all three pass 4.5:1 on every surface in both themes.
  • Dividers and card rings (--color-border-default) are decorative. Anything that identifies a control, such as an input edge, uses --color-border-strong (3:1).
  • Adding a brand theme: add a [data-theme="name"] block that overrides semantic tokens only, add its pairs to contrast-pairs.json and run the contrast check. See Theming.
