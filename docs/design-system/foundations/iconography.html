Iconography

Lucide-style 24-unit icons, sizes and labelling.

WCAG 2.2 AA
  • Overview
  • Set
  • Sizes
  • Usage
  • Tokens

Overview

Icons are Lucide-style outlines on a 24-unit grid with a 2px round stroke in currentColor, inlined as SVG with the .icon class. They support a label; they rarely replace one.

Usage

  • Decorative icons next to text are aria-hidden="true".
  • Icon-only buttons carry aria-label with the verb.
  • One icon means one thing: the cross-free map pin is a place, the flag is a report, the badge-check is vetted.
  • The brand seal is not an icon; see Brand lockup.
