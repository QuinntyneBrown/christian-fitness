Shape

Radii from keys to cards, and border widths.

WCAG 2.2 AA
  • Overview
  • Radii
  • Usage
  • Tokens

Overview

Soft and friendly: buttons, chips and avatars are pills; cards, images and dialogs have 24px corners. Radius grows with the element.

Radii

--radius-xs
--radius-sm
--radius-md
--radius-lg
--radius-xl
--radius-full

Usage

RadiusFor
xs 4pxKeys, ticks, focus outlines on text
sm 8pxChat bubble tail, skeleton titles, sign-out button
md 12pxInputs, date badges, icon tiles, group avatars, thumbnails
lg 16pxRows, alerts, toasts, stat tiles, chat bubbles
xl 24pxCards, images, tables, dialogs, panels
fullButtons, chips, badges, avatars, search and composer inputs

Borders are 1px hairlines; 2px marks the selected tab and focus rings.
