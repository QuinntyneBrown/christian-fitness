Layout

Breakpoints, columns, gutters, margins, containers and page templates.

Overview

Mobile first. Base styles target a 360px phone; breakpoints add margin, columns and navigation. The member app caps content at 80rem, the admin console at 72rem.

Breakpoints

BreakpointWidthColumnsGutterMarginWhat changes
base0–639px416px16pxBottom tab bar, one column, dialogs as bottom sheets
sm640px416px24pxMargins grow, two-column event grid and field rows, dialogs centre
md768px824px24pxTop navigation replaces the tab bar; messages show list and thread
lg1024px1232px24pxTwo-column pages (content + aside), admin sidebar, sticky asides
xl1280px1232pxautoContainer max reached; landing hero at 96px

Media queries use min-width in rem; custom properties cannot appear inside @media, so the values repeat --layout-breakpoint-* by convention.

Page splits use named ratios instead of spans: home 1.65fr / 1fr, event detail 1.6fr / 1fr, profile 1.4fr / 1fr, services 1fr / 1.1fr, dashboard 1.5fr / 1fr.

Page templates

  • Member shell: sticky top bar (64px), content in .container.page, bottom tab bar below md.
  • Auth: bordeaux brand aside and a 28rem form column side by side from lg; stacked below.
  • Admin shell: 16rem ink sidebar from lg (horizontal scroller above), page capped at 72rem.
  • Detail: banner image, then content and a sticky register aside from lg.
  • Messages: fills the viewport; 20rem conversation list beside the thread from md.

Usage

  • Use .container for page width and margin; never set page padding by hand.
  • Grids use minmax(0, 1fr) so long words do not blow out columns.
  • Full-height layouts use 100dvh.
  • Component sizes (--size-*) keep avatars, seals, date tiles and thumbnails consistent.
