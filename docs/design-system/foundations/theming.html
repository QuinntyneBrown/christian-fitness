Overview

Light is the default theme. Dark applies when the page sets data-theme="dark" on <html>, or when the OS prefers dark and the page has not forced data-theme="light". Each theme sets color-scheme so native controls and scrollbars follow.

Adding a theme

  1. Add [data-theme="name"] { … } to tokens.css, overriding semantic tokens only.
  2. Add the theme's pairs to contrast-pairs.json and run check_contrast.py.
  3. Regenerate tokens.json with tokens_to_json.py.
  4. Screenshot the component pages in the new theme.
[data-theme="dark"] {
  --color-bg-canvas: var(--palette-stone-950);
  --color-accent: var(--palette-bordeaux-600);
  color-scheme: dark;
}

How dark is built

Dark is built from roles, not by inverting light: surfaces rise from stone 950 to 850, the accent brightens one step so white labels still pass, text on blush-equivalent selected states uses rose, status backgrounds become deep tints with light text, the focus ring becomes borealis, and toasts invert to a light card.

Usage

  • Never read a primitive in a component; never hard-code a colour.
  • The Angular app imports tokens.css once as a global foundation and reads tokens by role in each component's encapsulated stylesheet.
  • tokens/tokens.json is the DTCG export ($type, $value, aliases as {group.token}, dark values under $extensions) for tooling and native platforms.
  • The theme toggle on these pages persists to localStorage; press t to switch.
