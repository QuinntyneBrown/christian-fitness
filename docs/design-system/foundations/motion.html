Foundation

Motion

Durations, easings, choreography and reduced motion.

WCAG 2.2 AA
  • Overview
  • Demos
  • Usage
  • Accessibility
  • Tokens

Overview

Motion is quick and quiet: it confirms a change and shows where something came from. Nothing loops except loading indicators.

Durations and easings

Usage

  • Hover and colour changes: fast (150ms), standard easing.
  • Card shadow, scrim, dialog scale-in, toast slide-up: base (200ms), enter easing.
  • Drawer and bottom sheet slide: slow (260ms), enter easing; exits use the exit easing.
  • Skeleton shimmer: deliberate (1.4s) loop; spinners 900ms per turn.
  • Tooltips wait 300ms before showing and hide immediately.

Accessibility

Under prefers-reduced-motion: reduce the duration tokens drop to 0.01ms, so transitions become instant without per-component media queries. Looping animations (spinner, shimmer, indeterminate progress) are switched off explicitly, and the loading text still says what is happening.
