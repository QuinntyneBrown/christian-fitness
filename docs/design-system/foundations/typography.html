Typography

Barlow and Barlow Condensed, the type scale, roles and measure.

Overview

Two self-hosted families from the prototype, both SIL OFL and bundled in assets/fonts/ (never a CDN): Barlow Condensed italic, uppercase, for display and page titles (.display), and Barlow for everything people read and operate. A system monospace serves code.

Roles

Role shorthands are complete font values: font: var(--text-h3). Display roles add text-transform: uppercase and --letter-spacing-wide through .display.

Usage

  • One display heading per screen (the page title); section titles are Barlow semibold 24px.
  • Weights: 400 body, 500 display, 600 labels and emphasis, 700 badges and counts.
  • Prose is capped at --layout-measure (42rem, about 75 characters).
  • Numbers in tables, schedules and stats use font-variant-numeric: tabular-nums.
  • Display headings scale by breakpoint, not by viewport units: the landing hero is 60 → 72 → 96px; page titles 36 → 48px.

Accessibility

  • Sizes are in rem, so browser zoom and the user's default font size scale everything.
  • Body text is 16px with 1.5 line height; nothing below 12px (the prototype's 11px tab labels were raised).
  • Uppercase is limited to display headings and short overlines, which assistive technology reads from the source text in sentence case.
  • Layouts survive WCAG 1.4.12 text spacing: no fixed heights on text containers.
