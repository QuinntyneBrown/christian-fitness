Steps

Steps tell people what happens after they send something: a short numbered list beside the form, and a thank-you that says the same in a sentence.

Overview

Three small blocks used by the member forms that send something to the team:

  • Steps (.steps): "What happens next", a numbered list joined by a thin line, beside the Suggest a listing form and its success state. It is information, not a progress tracker: no step is current or done.
  • Done (.done): the success state that replaces a sent form: a check, a thank-you by name, what happens now, and two ways on. It takes focus and is announced.
  • Context chip (.context-chip): "About this page" on the feedback form, naming the page the feedback came from, with a button to remove it.

For progress through a multi-screen task use a page title and a back link (there is no stepper in this product); for a quick confirmation use a toast; for a form-level message an alert.

Anatomy

  1. Number.steps__n: a 32px circle (--space-8), surface with a hairline ring, accent display figure; aria-hidden because the list is ordered.
  2. Title.steps__title: semibold, one short sentence.
  3. Text.steps__text: 15px muted, relaxed leading.
  4. ConnectorA hairline from each number to the next (::before), not after the last step.

Sizes

One size each. Steps: 32px numbers, 16px gap, 24px between steps. Done: 48px icon circle (--size-avatar-xl), page-title heading, 18px text up to --layout-lead-max. Context chip: 12px × 16px padding.

States

Steps are static. Done has one state in each variant, shown once, focused on arrival (the ring sits 8px out); the alert variant differs only in its icon and role. The context chip's only control is its remove button (hover, focus).

  • Done uses role="status" and receives focus (tabindex="-1", autofocus in the mock) so a screen reader reads the thanks and keyboard users start from it.
  • Done's alert variant (claim-listing/expired; ADR 0092) is the same block for a way that ended: a clock in place of the check and role="alert", so it is announced at once. It still takes focus, and has one way on.
  • Removing the context chip sends the feedback without a page; the mocks do not draw that state.

Responsive behaviour

  • Steps sit in the form page's aside: below the form on phones, a second column from 1024px, pushed down (.form-page__aside--low) to line up with the first field.
  • Done's actions wrap onto two lines on narrow phones.
  • The context chip fills the form's width; its value truncates to one line.

Theming

Step numbers: --color-bg-surface, ring --color-border-default, figure --color-fg-accent; connector --color-border-default; text --color-fg-muted. Done's icon is --color-accent/--color-fg-on-accent. The context chip is a surface with a hairline ring and a muted label.

Accessibility

Role and pattern

Steps: an <ol> under a heading; the visible numbers are aria-hidden because the list announces position. Done: a <section role="status" tabindex="-1"> with the page's <h1>, focused when shown; its alert variant is role="alert", for an outcome the person did not expect (an expired link). The icon is aria-hidden in both: the heading says what happened. Context chip: text plus an icon button named "Remove page".

Keyboard

KeyAction
TabFrom Done: Back to the directory, then Suggest another. On the chip: the Remove page button.
EnterFollows a Done action; removes the page.

Focus

Done draws the shared ring 8px outside itself (--space-2) when it receives focus.

Labelling

Steps read "list, 4 items: We read it within 3 days. A real person on our team, not a filter." The chip's button name could say which page ("Remove page: Couch to 5K Run Club").

Contrast

Step number

Motion

None.

Touch

Steps have no targets. Done's buttons are 44px tall. The chip's remove button is 32px and extends to 44 × 44px on coarse pointers.

Content

  • Step titles say who does what, in the present: "We read it within 3 days", "You hear back". Texts add the one detail that reassures.
  • Done thanks by first name when there is one ("Thanks, Grace"), names what was sent in bold, says what happens next and when.
  • Done, alert: the heading says what ended ("This link has expired"), the text the one thing to do ("Ask us for a new one."), and one way on. No thanks, no blame.
  • Chip: "About this page" + "Section › Title".
