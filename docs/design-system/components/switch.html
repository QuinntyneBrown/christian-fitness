Switch

A switch turns a setting on or off the moment it is flipped, with no Save button.

WCAG 2.2 AAStatus: new<input type="checkbox" role="switch">

Overview

Use a switch for a setting that applies immediately: privacy, notifications. If the change waits for a form submit, use a checkbox. Pair each switch with a label that names the setting, and say what changed in a toast only if it is not obvious.

  • Trailing (default): label left, switch right, as in settings lists.
  • Leading (.switch--start): switch before the label for short inline settings.

Anatomy

  1. LabelSemibold 15px; names the setting.
  2. Description (optional)Muted 14px; says what on means.
  3. Track and thumb--size-switch-w × --size-switch-h; grey off, bordeaux on, thumb slides.

Variants

Trailing, in a settings list.
HTML
<label class="switch"><span class="switch__text"><span class="switch__label">Show me on event attendee lists</span><span class="switch__desc">Other members see your first name and photo</span></span><input class="switch__input" type="checkbox" role="switch" checked></label><label class="switch"><span class="switch__text"><span class="switch__label">Message notifications</span><span class="switch__desc">A push notification for each new message</span></span><input class="switch__input" type="checkbox" role="switch"></label>
Leading.
HTML
<label class="switch switch--start"><span class="switch__text"><span class="switch__label">Show my home church</span></span><input class="switch__input" type="checkbox" role="switch"></label>

Sizes

One size, set by --size-switch-w and --size-switch-h; the row is at least 44px tall.

States

Pointer and focus forced with data-state; checked and disabled are real attributes. There is no invalid state: a switch cannot be wrong. If saving fails, flip it back and show an error toast.

VariantDefaultHoverFocusCheckedDisabled
Off
On—

Both themes

  • Busy: while saving, keep the new position and set aria-busy on the row; on failure revert and explain.
  • Disabled dims the row; say why nearby ("Turn on notifications in your browser first").

Responsive behaviour

Trailing switches stay at the row end at every width; long labels wrap beside them.

Theming

Track off uses --color-border-strong, on --color-accent; the thumb is --color-bg-surface with --shadow-1. All switch with the theme.

Accessibility

Role and pattern

A native checkbox with role="switch", so it is announced as on/off (APG Switch). The wrapping label names it.

Keyboard

KeyAction
TabMoves focus to the switch.
SpaceToggles it.

Focus

2px --color-focus-ring outline at 2px offset around the track.

Labelling

The label names the setting, not the state ("Message notifications", not "On"); the role announces on or off. The thumb position plus the fill carry the state, not colour alone.

Contrast

Label
Description

Motion

Thumb and track transition over --duration-fast; instant under reduced motion.

Touch

The whole row is the target, at least 44px tall.

Content

  • Label the setting in plain words: "Show me on event attendee lists".
  • Describe what on means, not both states.
  • Never put "On"/"Off" text next to it.
