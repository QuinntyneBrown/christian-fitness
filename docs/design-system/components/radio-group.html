Radio group

A radio group asks for exactly one choice from a short list, with every option in view.

WCAG 2.2 AAStatus: newNative <input type="radio">

Overview

Use radios for two to five options people should compare before choosing. For longer lists use a select; for any number of choices use checkboxes; for switching a view use tabs.

  • List: stacked options with optional descriptions.
  • Row (.choice-group--row): short labels side by side, wrapping.
  • Card (.choice-card): bordered options; the chosen card fills with the accent tint.

Anatomy

  1. LegendThe question, as .field__legend.
  2. RadioNative 20px radio tinted with accent-color.
  3. LabelSemibold; the whole label selects.
  4. Description (optional)Muted 14px.

Sizes

One size: 20px radio, 15px label, rows at least 44px tall.

States

Pointer and focus forced with data-state; checked, disabled and invalid are real attributes.

Both themes

Where would you like to meet?
  • No preselection when there is no safe default; then leaving it empty shows the error "Choose where you'd like to meet".
  • Checked card uses :has(:checked): tint plus a 2px accent border, so the state is not colour alone.

Responsive behaviour

  • Row groups wrap; under 360px they read as a list.
  • Cards stack full width on phones and may sit in a .field-grid from 640px.

Theming

Radios are tinted by accent-color. Card borders use --color-border-strong, checked cards --color-accent-subtle and --color-accent, all of which switch with the theme.

Accessibility

Role and pattern

Native radios sharing a name, inside <fieldset> with <legend> (APG Radio group).

Keyboard

KeyAction
TabMoves into the group (to the checked radio, or the first) and out again.
↓ / →Selects the next option.
↑ / ←Selects the previous option.
SpaceSelects the focused option if none is selected.

Focus

2px --color-focus-ring outline at 2px offset around the radio.

Labelling

The legend names the question, each label an answer. The group error is linked from the fieldset and every radio gets aria-invalid.

None.

Touch

The whole label or card is the target, at least 44px tall, 8px apart in rows.

Content

  • The legend is a question: "Where would you like to meet?".
  • Options are parallel and short; descriptions add the consequence.
  • Order options logically, not alphabetically.
