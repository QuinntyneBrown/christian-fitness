Menu

A menu button gathers several actions behind one trigger, so a busy row or header stays calm. Open it, pick one, and it closes.

WCAG 2.2 AAStatus: newAPG Menu button

Overview

Use a menu when one object has three or more secondary actions that do not fit in its row: an admin event row (Edit, Duplicate, Message attendees, Cancel event) or the profile button in the top bar. With one or two actions, show buttons. For choosing a value in a form, use a select or radio group; a menu runs actions, it does not hold a value (except a sort or view choice with menuitemradio).

  • Action menu: plain menuitems, grouped in sections, destructive last in danger colour.
  • Choice menu: menuitemradio with a check on the selected option, under a heading.

Anatomy

  1. TriggerA button with aria-haspopup="menu" and aria-expanded; its label names the set.
  2. Menu surfaceRaised surface, --radius-lg, --shadow-2 plus a hairline, at --z-dropdown.
  3. ItemFull-width button, icon optional, 44px min-height; aria-disabled when unavailable.
  4. Section divider and danger itemSections split by a hairline; the destructive item sits alone at the end.

Sizes

One size. Items are 15px with at least 44px height (--target-comfortable); the surface is at least 192px wide and grows to its longest label.

States

The trigger is a button and takes its states. Items are shown with forced data-state; real menus move focus with the arrow keys and style :focus-visible.

Sort by

Sort by

  • Open sets aria-expanded="true" on the trigger and removes hidden from the menu.
  • Disabled items stay focusable with aria-disabled so people learn they exist; activating does nothing.

Responsive behaviour

  • The menu aligns to the trigger's inline end and flips upward when there is no room below.
  • Under 640px a long menu may open as a bottom sheet dialog instead.
  • Labels wrap rather than truncate.

Theming

The surface reads --color-bg-surface-raised, which lifts in the dark theme so the menu separates from the page without a heavier shadow. Item hover uses --color-bg-subtle; danger uses --color-danger-fg.

Accessibility

Role and pattern

APG Menu button: trigger with aria-haspopup="menu", aria-expanded, aria-controls; the list has role="menu" labelled by the trigger; items are menuitem or menuitemradio with roving tabindex.

Keyboard

KeyAction
Enter, Space, ↓On the trigger: opens the menu and focuses the first item.
↑On the trigger: opens and focuses the last item.
↓ / ↑Moves between items, wrapping.
Home / EndFirst or last item.
Enter, SpaceActivates the item and closes the menu.
EscCloses and returns focus to the trigger.
TabCloses the menu and moves on.

Focus

Focused items get the subtle background plus an inset 2px --color-focus-ring, so focus never depends on the background alone. Closing returns focus to the trigger.

Labelling

The menu is labelled by its trigger (aria-labelledby). Icon-only triggers name the object: aria-label="Actions for Saturday run".

Contrast

Item on raised surface
Danger item
Heading

Motion

Opens with a 4px fade-down over --duration-base (--ease-enter); reduced motion zeroes it. Closing is instant.

Touch

Items are at least 44px tall. Tapping outside closes the menu.

Content

  • Items are verbs: "Edit event", "Duplicate", "Cancel event".
  • Destructive items name what is lost and open a confirmation.
  • Choice headings are short: "Sort by".
  • Trigger label names the set ("Actions") or, if icon-only, the object.
