Checkbox

A checkbox turns one thing on or off as part of a form, or lets people pick any number from a list.

WCAG 2.2 AAStatus: stableNative <input type="checkbox">

Overview

Use a checkbox when the choice takes effect on submit ("It's fine to tell them you suggested them") or when several options can be picked together. Use a switch for a setting that applies immediately, a radio group for exactly one choice, and a chip for filters people toggle often.

  • Compact (.check): 14px semibold, for filter bars ("Only events I'm going to").
  • Form (.check.check--ui): 15px, wraps, for confirmations inside forms.
  • Group with descriptions (.choice in .choice-group): a fieldset of options, each with a bold label and a muted description.

Anatomy

  1. LegendNames the group (.field__legend).
  2. BoxNative checkbox, 20px in groups (16px compact), tinted with accent-color.
  3. LabelSemibold, part of the wrapping <label>, so it toggles the box too.
  4. Description (optional)Muted 14px under the label.

Sizes

Compact boxes are 16px (--size-icon-sm), group boxes 20px (--size-icon-lg). Each row is at least 44px tall in groups.

States

Pointer and focus forced with data-state; checked, disabled and invalid use real attributes. Indeterminate is set by script (el.indeterminate = true) for a parent of a partly checked list.

Both themes

  • Invalid (a required confirmation left unchecked) adds aria-invalid and a field error: "Confirm you've checked their credentials before listing them".
  • Disabled dims the label to --color-fg-disabled.
  • Busy (a box in a list that saves as it is ticked, such as Came on Attendance; ADR 0106) adds aria-busy="true" and its words read "Saving…" while the change is saved. It stays enabled, so focus stays on it and a failed save can put it back.

Responsive behaviour

  • Compact checks never wrap (filter bars scroll instead).
  • Form checks and groups wrap their labels; the box stays top-aligned.

Theming

The native box is tinted by accent-color: var(--color-accent), which follows the theme. The browser draws the tick, so it adapts automatically.

Accessibility

Role and pattern

Native checkbox inside a <label>. Groups use <fieldset> and <legend> (APG Checkbox).

Keyboard

KeyAction
TabMoves to each checkbox in turn.
SpaceToggles the focused checkbox.

Focus

The shared 2px --color-focus-ring outline at 2px offset around the box.

Labelling

The wrapping label is the name; descriptions are inside the label so they are read with it. A box whose words change (Came, then Saving…) is named by aria-label ("Came: Grace Thompson"), so its name holds while it saves. Group errors link from the fieldset with aria-describedby.

Motion

Touch

The whole label is the target; group rows are at least 44px (--target-comfortable). Compact checks in the filter bar extend with padding.

Content

  • Labels state what is true when checked: "It's fine to tell them you suggested them".
  • Never negative ("Don't send me news").
  • Confirmations are first person: "I've checked their registration, insurance and two references".
