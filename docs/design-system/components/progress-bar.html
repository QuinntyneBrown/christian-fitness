Progress bar

A progress bar shows how far along a task is; a meter shows how full something is, like an event's spots.

WCAG 2.2 AAStatus: stablerole="progressbar" · native <meter>

Overview

Use a progress bar for a task the person started that takes more than a couple of seconds and whose length is known (uploading a cover photo or professional credentials). Use the indeterminate bar when the length isn't known. Use a meter (.fill__meter) for a measurement, not a task: how many of an event's spots are taken on the admin dashboard.

For waits under a few seconds use a spinner or a busy button; for content loading, a skeleton.

Anatomy

  1. Label.progress__label, 14px semibold; also the bar's accessible name.
  2. Value.progress__value, tabular, muted. Optional.
  3. Track and bar6px (--size-meter) pill track; the bar's width is --progress.

Meter

Admin dashboard fill: native <meter>, named with the event and the count.
HTML
<meter class="fill__meter" min="0" max="200" value="142" aria-label="Easter Sunrise 5K: 142 of 200 registered"></meter>

Sizes

One height, --size-meter; the bar fills its container's width.

States

States are tones applied to the whole bar, plus the indeterminate mode. Set aria-valuenow with the width; a finished or failed bar keeps its label in words.

Both themes

Uploading cover photo64%
Uploading cover photo64%
  • Complete turns green and changes the label ("Cover photo uploaded"); the bar then leaves or the next step appears.
  • Failed turns red and is paired with an inline message offering a retry.
  • Indeterminate slides a 40% bar; it omits aria-valuenow.

Responsive behaviour

The bar is fluid. On phones the label and value stay on one row; a long label wraps and the value stays right-aligned.

Theming

The bar uses --color-accent (or --color-success-solid / --color-danger-solid) on a --color-border-default track. Dark values brighten the accent so the bar keeps 3:1 against the track's surface.

Accessibility

Role and pattern

The track carries role="progressbar" with aria-label, aria-valuemin, aria-valuemax and aria-valuenow. A meter is the native <meter> with an aria-label stating the count in words. Announce completion through the page's polite status region, not by every percent.

Keyboard

KeyAction
TabNot focusable; the label and value are read in reading order.

Focus

{'na': 'Progress bars and meters are not interactive.'}

Labelling

The label says what is progressing ("Uploading cover photo"); the value is visible text too, so colour and length are never the only carriers.

Motion

Width changes ease over --duration-base. The indeterminate slide runs over --duration-deliberate; under reduced motion it stops and shows a full, faded bar.

Touch

{'na': 'Not interactive.'}

Content

  • Label in the present participle while running ("Uploading cover photo"), past tense when done ("Cover photo uploaded").
  • Value as a percentage, or a count for meters ("142 of 200").
  • Never only a percentage with no label.
