List

Lists show items people read one at a time: the next events, their conversations, the events they're going to.

WCAG 2.2 AAStatus: stableNative <ul> / <ol>

Overview

Use a list when each item stands on its own and opens something. Use a table when staff compare columns, and a description list for name–value facts.

  • Event row (.event-row) in a .list-ruled: date column, title and meta, an end value (price or "Going"). Home and the events list.
  • Rail event row: the same row with no end slot in a .list-divided, under "Upcoming events" in the landing page's rail. For signed-out visitors each row links to Join; a static, non-link form with a wrapping title (.event-row__title--wrap) lists events in the newsletter.
  • Mini row (.mini-row) in a .mini-list: avatar, name, time and last line; home's message preview.
  • Conversation (.conversation): the mini row inside the inbox, with a current state.
  • Going item (.going-item): a thumbnail card row on the profile.
  • Ruled and divided lists (.list-ruled, .list-divided, .goals, .card--list): plain hairline-separated lists for static text or service rows.

Anatomy

  1. Date column.event-row__date: 12px uppercase accent month over a 24px display day, --size-date-col wide.
  2. TitleSemibold, one line with ellipsis; turns accent on hover.
  3. Meta14px muted: weekday, time and area.
  4. End.event-row__end: price, or "Going" in accent semibold.

  • Event rows and mini rows have no disabled state: an item that cannot be opened is not a link.
  • Current applies to conversations only (aria-current="true", accent-subtle background).
  • Unread pairs bold text with a dot or count that has an aria-label, so weight is not the only signal.

Responsive behaviour

  • Titles, meta and last lines truncate to one line with an ellipsis; the end slot never shrinks.
  • Large event rows and .event-row__title--wrap let the title wrap; the landing rail keeps one line because the rail is narrow beside the stories from 1024px and full width below.
  • On phones the inbox shows the conversation list or the thread, never both; from --layout-breakpoint-md the list sits beside the thread at --layout-conversations-width.

Theming

Rows read --color-fg-default, --color-fg-muted and --color-fg-accent; hover uses --color-bg-surface (mini row) or --color-bg-canvas (conversation); current uses --color-accent-subtle. All are themed tokens, so dark mode needs no overrides.

Accessibility

Role and pattern

A <ul> of <li>, each holding one <a> that wraps the whole row. Lists that are not sections of their own take an aria-label ("Professionals").

Keyboard

KeyAction
Tab / Shift + TabMoves from row to row.
EnterOpens the event or conversation.

Focus

The shared 2px ring wraps the whole row; rounded rows (mini, conversation, going item) follow their radius.

Labelling

The row's text is its name, read in order: month and day, title, meta, end. Avatars and thumbnails are decorative. Unread dots and count pills carry role="img" or an aria-label ("3 unread").

Contrast

Title
Meta and time
Month and Going
Current conversation

Motion

Colour and background transitions over --duration-fast; the arrow nudges 2px on hover. Reduced motion removes both.

Touch

Every row is at least 56px tall and full width, well above the 44px target.

Content

  • Meta reads "Sat 8:00 AM · Waterfront": weekday, time, area, joined by a middle dot.
  • Times in message rows are relative to today: "8:42 AM", "Yesterday", "Mon", then "Apr 9".
  • Last lines in group chats lead with the first name: "Michael: Parking at…".
  • End values are short: "$10", "Free", "Going".
