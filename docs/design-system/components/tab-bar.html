Tab bar

On phones the tab bar keeps the five places of the member app one thumb away.

WCAG 2.2 AAStatus: stable<nav> of linksFixed, phones only

Overview

The tab bar is the mobile half of primary navigation in the member app: Home, Events, Directory, Services, Messages and Profile, each an icon above a label. It is fixed to the bottom of the viewport below 768px and hidden above, where the top bar's links take over.

  • Use it on every signed-in member screen, including full-height ones like Messages.
  • It is navigation, not a set of tabs: each item is a link to a page, never a panel switcher.
  • Do not use it in the admin console (sidebar) or on public pages (site header).

Anatomy

  1. Icon24px (icon--lg), aria-hidden; it inherits the item colour.
  2. Label12px semibold (--font-size-xs), always visible; it is the link's name.
  3. Unread dot.tab-bar__dot, an 8px bordeaux dot, paired with a visually hidden ", 4 unread" so the dot is never the only signal.
  4. BarFive equal columns, 64px tall (--layout-tabbar-height), surface background, hairline top border.

Sizes

One size: 64px tall, five equal columns across the full width.

States

Items are links. Current is aria-current="page", shown by bordeaux colour on icon and label. There is no hover fill: the bar only appears on touch-sized screens.

Both themes

HomeEventsDirectoryServicesMessages, 4 unreadProfile
  • Current changes colour and is announced through aria-current; colour is never the only carrier because the page title also changes.
  • Items never disable. Offline, each place opens and explains itself.
  • No press animation: the page change is the feedback.

Responsive behaviour

  • Shown below 768px (--layout-breakpoint-md), hidden from 768px.
  • Pages reserve --layout-tabbar-height at the bottom of .app__main so the last item is never covered.
  • Labels never truncate; at 320px each of the six columns is 53px wide and "Directory" and "Messages" still fit (measured on pages/home/default).
  • On devices with a home indicator, the shipping app adds env(safe-area-inset-bottom) below the items.

Theming

Reads --color-bg-surface, --color-border-default, --color-fg-muted for items and --color-fg-accent for current and the dot's --color-accent. Dark theme swaps all of them through the semantic tier.

Accessibility

Role and pattern

A <nav aria-label="Primary, mobile"> of links, after <main> in the DOM. It is not an ARIA tablist; arrow keys do nothing special.

Keyboard

KeyAction
Tab / Shift + TabMoves between items.
EnterFollows the link.

Focus

The shared 2px --color-focus-ring, offset inward far enough to stay inside the bar.

Labelling

Visible labels name every item. The unread dot is aria-hidden; the hidden text ", 4 unread" makes the link read "Messages, 4 unread".

Contrast

Item label
Current item
Unread dot

Motion

None. The bar is fixed and never hides on scroll.

Touch

Each item is the full column by 64px, well over 44 × 44px.

Content

  • Exactly five items, one word each: Home, Events, Services, Messages, Profile.
  • Labels match the top bar's links word for word.
