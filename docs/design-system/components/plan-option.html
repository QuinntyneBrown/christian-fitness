Plan option

A plan option is one way to take part in an event series, with what it means and what it costs: every session, or the dates you pick.

Overview

Use plan options in a series' Sign up panel, where a member decides how to come before pressing the panel's one button: Every session (join the whole program, the spot held each week) or Pick dates to drop in (tick dates in the session list). Each option shows a title, a short note that changes with the state, and the price for that choice.

  • Plan option (.plan-option): a radio drawn as a full-width row card; the chosen one fills with the accent tint and an accent ring.
  • Plan list (.plan-list): the borderless <fieldset> that stacks them 8px apart, with a visually hidden legend.

For answers without a price, use choice cards or a radio group.

Anatomy

  1. Radio.plan-option__input: the native radio, 16px (--size-icon-sm), tinted with accent-color.
  2. Title.plan-option__title: semibold, with the count when it matters: "Every session (5 left)".
  3. Note.plan-option__note: 14px muted; says what the choice means now ("Your spot is held each week", "2 picked below").
  4. Price.plan-option__price: Barlow Condensed (--font-family-display) 20px semibold, never shrinks: "$64 for all 8", "$10 each", "Free".

Sizes

One size: 16px padding all round, so an option with a note is about 70px tall; it fills the panel's width. The radio is 16px; the whole row is the target.

States

Checked and disabled are real attributes on the radio; the row styles itself from them with :has(). Hover is real :hover only (the block has no data-state hook), so it is not forced here. Focus is forced with data-state on the row, which draws the same ring :has(:focus-visible) draws live. States run down the table here, since the row is wide.

  • Busy: while "Joining…" or "Registering…" runs, both options are disabled (the chosen one keeps its fill) and dim to --opacity-unavailable.
  • Full: "Every session" is disabled with the note "Every place in the series is taken"; there is no waitlist (mocks README: Series, full).
  • Failed: the options stay as chosen; the error appears above the panel's button.
  • Joined or booked: the options give way to the confirmation; a member changes dates from there.

Responsive behaviour

  • The options fill the Sign up panel at every width: the panel sits beside the sessions from 1024px and under them on phones.
  • The price never shrinks (flex-shrink: 0); the title and note wrap beside it. At 360px "$64 for all 8" keeps one line and the note wraps to two.

Theming

Unchosen: transparent with a hairline --color-border-default ring (--color-border-hover on hover). Chosen: --color-accent-subtle and a hairline --color-accent ring. Note in --color-fg-muted; radio tint --color-accent. All follow the theme.

Accessibility

Role and pattern

Native radios in a <fieldset> with a visually hidden <legend> "How would you like to come?" (APG Radio Group, natively). The whole row is the radio's <label>, so title, note and price are its name.

Keyboard

KeyAction
TabMoves into the group (to the chosen option) and on to the panel's button.
↑ / ↓Chooses the other option.
SpaceChooses the focused option if none is chosen.

Focus

The shared 2px --color-focus-ring at 2px offset around the whole row, from :has(.plan-option__input:focus-visible).

Labelling

The legend names the question for screen readers; each row reads as "Every session (5 left), Your spot is held each week, $64 for all 8". The chosen row is marked by the filled radio and the ring as well as the tint. A disabled option keeps its note, which says why.

Motion

Touch

Content

  • Titles say what you sign up for: "Every session (5 left)", "Pick dates to drop in".
  • The note says what it means now and changes with the state: "Your spot is held each week", "Come when you can", "Tick dates in the list", "2 picked below", "Every place in the series is taken".
  • Prices in full and plain: "$64 for all 8", "$10 each", "Free". No payment happens online yet; the panel says to pay the host.
