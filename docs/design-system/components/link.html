Link

Links take people somewhere: another page, a section, a profile, a partner's site. They never change anything on their own.

WCAG 2.2 AAStatus: stableNative <a href>

Overview

Use a link when activating it navigates. Use a button when it changes something (register, send, retry), even if it should look like a link: that is .btn--link.

  • Inline link (.link) sits inside running text: underlined, in the link colour, so it is never told apart by colour alone.
  • Text link (.text-link) is a standalone semibold link beside a section heading: "All events →", "Open". The quiet form (.text-link--quiet) recedes in muted text.
  • Back link (.back-link) leads to the parent list at the top of a detail page: "← All events".
  • External link adds the small out-arrow (.link__external) and says so to screen readers.

Anatomy

  1. LabelThe words that say where it goes; they are the accessible name.
  2. External icon (optional)12px (--size-icon-xs) out-arrow, aria-hidden, paired with visually hidden "(opens in a new tab)".
  3. UnderlineOffset by --space-0-5; thickens on hover so the state does not rely on colour.

Sizes

Links take the size of their context. Inline links inherit the paragraph's size; text and back links are 14px semibold (--font-size-sm). There is no size modifier.

States

Pointer and focus states are forced with data-state; live pages use :hover, :focus-visible and :active. A link that points at the current page carries aria-current="page". Links have no disabled state: remove the link and show plain text instead.

  • Visited is not styled: most links are app navigation where "visited" means nothing.
  • Disabled does not exist. A link that cannot go anywhere is text.
  • Current uses aria-current="page"; navigation components (tabs, sidebar) style it.

Responsive behaviour

  • Inline links wrap with their sentence; never set white-space: nowrap on long names.
  • Under (pointer: coarse) text links extend their hit area to 44 × 44px with a pseudo-element.
  • Back links collapse a breadcrumb on phones: the parent becomes the back link.

Theming

Inline links read --color-fg-link and --color-fg-link-hover; text links read --color-fg-accent. In the dark theme both lift to lighter bordeaux tints so they keep 4.5:1 on dark surfaces. Re-skin by reassigning the semantic tokens, never by colouring a single link.

Accessibility

Role and pattern

Native <a href> (APG Link). Never a <span> with a click handler, never an <a> without href.

Keyboard

KeyAction
Tab / Shift + TabMoves focus to and from the link.
EnterFollows the link (Space scrolls the page, as browsers do).

Focus

The shared ring, 2px --color-focus-ring at 2px offset, on :focus-visible; --radius-xs rounds it around inline links.

Labelling

The link text says where it goes out of context: "All events", not "Click here" or "More". When a row repeats "Open", add hidden context: Open<span class="visually-hidden"> Saturday run chat</span>. New-tab links say so in hidden text.

Motion

No motion. Colour and underline thickness change instantly.

Touch

Text links extend to 44 × 44px on coarse pointers. Inline links in body text are exempt (WCAG 2.5.8 inline exception) but keep at least one line of space between stacked links.

Content

  • Name the destination: "All events", "Community guidelines", "Danielle's profile".
  • Sentence case; no trailing full stop inside the link.
  • Back links name the parent ("All events"), not "Back".
  • Do not link a whole sentence; link the noun phrase that names the place.
