Description list

Description lists pair a name with its value: when and where an event is, a professional's credentials and rate.

WCAG 2.2 AAStatus: stableNative <dl>

Overview

Use a description list for the facts of one thing. Use a table to compare many things, and a list for items that open.

  • Facts (.facts): icon, a bold term and a muted detail. Event detail's date and place.
  • Spec list (.spec-list): muted term on the left, bold value on the right, hairlines between. A professional's credentials and rate.
  • Stat grid (.stat-grid): label and big number tiles; documented on Stat.

Anatomy

  1. Term<dt>, muted 15px; names the value.
  2. Value<dd>, semibold, right-aligned; wraps under itself on narrow widths.
  3. RuleHairline --color-border-default between pairs; each pair is a <div> inside the <dl>.

Sizes

One size each. Facts stack with a 16px gap (--space-4) and 24px icons; spec rows have 12px block padding (--space-3).

States

Description lists are static text: no hover, focus, active or disabled. A value can contain a link, which brings its own states. The only list states are loading and a missing value.

Responsive behaviour

  • Spec values wrap and stay right-aligned; on very narrow widths the value wraps under its own column, never under the term.
  • Facts are a single column at every width.

Theming

Terms read --color-fg-muted (spec) or --color-fg-default (facts), values the opposite; icons --color-fg-accent; rules --color-border-default. No component tokens; dark mode comes from the semantic tokens.

Accessibility

Role and pattern

Native <dl> with <dt>/<dd>, grouped in <div>s (valid HTML). Screen readers announce the list and the number of terms.

Keyboard

KeyAction
TabReaches only links inside values; the list itself is not focusable.

Focus

None on the list. Links inside values use the shared ring.

Labelling

Terms label their values. Fact icons are aria-hidden; the term already says "Sat, Apr 18".

Content

  • Terms are short nouns: "Credentials", "Rate". Values are specific: "$95 first consult".
  • Dates as "Sat, Apr 18"; times as "6:45 AM · about 90 minutes".
  • Optional personal details show "Not shared", never "N/A".
