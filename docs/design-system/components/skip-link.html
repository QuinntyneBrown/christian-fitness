Skip link

The skip link is the first thing a keyboard user reaches on every page. It jumps past the header straight to the content.

WCAG 2.2 AAStatus: stableWCAG 2.4.1 Bypass blocks

Overview

Every page in both apps starts with <a class="skip-link" href="#main">Skip to content</a> as the first child of <body>. It sits off screen until it receives focus, then slides into the top-left corner as a bordeaux pill. Activating it moves focus to <main id="main">.

There is one variant. Pages with a long filter bar still skip to main, never into the middle of a form.

Anatomy

  1. Label"Skip to content", 15px semibold, white on bordeaux.
  2. ContainerPill (--radius-full), padding --space-2 / --space-4, above everything (--z-tooltip).

Variants

Skip to content
The only variant, shown in its focused position.
HTML
<a class="skip-link" href="#main" data-state="focus">Skip to content</a>

Sizes

A skip link has one size.

States

The skip link has two states that matter: hidden (not focused) and shown (focused). It has no hover, active or disabled styling beyond the shared focus ring.

StateAppearance
DefaultPositioned at top: calc(-1 * var(--space-24)), off screen, still in the tab order.
Focus.skip-link:focus moves it to top: var(--space-2) with the focus ring.
Hover, active, disabled—

Both themes

In the dark theme the pill reads the brighter dark accent so the white label keeps 4.5:1; the ring turns borealis.

  • Never hide it with display: none or visibility: hidden; that removes it from the tab order.
  • The target main needs id="main"; add tabindex="-1" only if a browser fails to move focus.

Responsive behaviour

Identical at every width: left: var(--space-4) matches the page gutter on phones. Touch users rarely meet it; it costs nothing.

Theming

Reads --color-accent and --color-fg-on-accent, the same pair as the primary button, so it themes with it.

Accessibility

Role and pattern

A native same-page link (<a href="#main">) satisfying WCAG 2.4.1. It must be the first focusable element.

Keyboard

KeyAction
TabFrom page load, the first press shows and focuses the skip link.
EnterMoves focus to the main landmark; the next Tab goes to the first control in it.

Focus

The shared 2px ring at 2px offset, plus the move into view. It is never covered by the sticky header (--z-tooltip sits above --z-sticky), satisfying 2.4.11 Focus not obscured.

Labelling

"Skip to content" is the accessible name. Do not add aria-label.

Contrast

Label on pill
Focus ring on surface

Motion

It appears instantly; no slide transition.

Touch

Padding gives a target about 40px tall and over 140px wide, above the 24px minimum of 2.5.8.

Content

  • Always "Skip to content": same words on every page in both apps.
  • Sentence case, no full stop.
