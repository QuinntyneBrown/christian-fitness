Message

Messages keep event groups and friends talking between events: bubbles, day separators and a composer.

WCAG 2.2 AAStatus: stableReal-time via SignalR<ol> of messages

Overview

  • Received (.message): surface bubble on the left, with the author's name in group chats.
  • Mine (.message--mine): bordeaux bubble on the right, no author.
  • Failed (.message--failed): faded bubble with "Not sent. Try again".
  • Day separator (.thread__day): "Today", "Yesterday", "Mon, Apr 13".
  • Composer (.composer): pill input and round send button at the foot of the thread.

Conversation lists are documented under List.

Anatomy

  1. Author12px semibold muted; group chats only, never on your own messages.
  2. Bubble--radius-lg with a --radius-sm tail corner toward the sender; 15px text.
  3. Time12px muted under the bubble, aligned with it.

Sizes

One size. Bubbles grow to 80% of the thread width on phones and 65% from --layout-breakpoint-sm.

States

Bubbles are text, not controls; they have no hover or focus. The composer's input and send button have the interactive states. Sending and failed belong to my messages.

  • Failed fades the bubble and adds a role="alert" line with an icon, "Not sent." and a "Try again" button; the text is kept so nothing is lost.
  • Draft: with text in the input, send is enabled; leaving keeps the draft (messages draft).
  • Loading draws bubble skeletons (.skeleton--bubble); empty shows "No messages yet. Say hello."

Responsive behaviour

  • Phones show the thread full screen with a back button; from --layout-breakpoint-md it sits beside the conversation list.
  • The composer stays pinned to the bottom of the panel; the message list scrolls above it.
  • Long words and links wrap inside the bubble.

Theming

Received: --color-bg-surface with a --color-border-default ring on the --color-bg-canvas thread. Mine: --color-accent/--color-fg-on-accent. Failed text: --color-danger-fg. Composer focus border: --color-accent.

Accessibility

Role and pattern

The thread is an <ol> in a labelled section; new messages are announced through a polite live region owned by the real-time client, not by each bubble. The composer is a <form> with a visually hidden label.

Keyboard

KeyAction
EnterSends the message from the input.
TabMoves from the input to Send, then to any Try again.

Focus

The composer input shows an accent border on focus in addition to the shared ring on the send button.

Labelling

Input label: "Message Sunrise 5K Crew". Send button: aria-label="Send". Failed: the alert reads "Not sent. Try again". Message text is rendered as text, never HTML.

Motion

The list scrolls to the newest message instantly; no slide-in animation. Send fades between enabled and disabled over --duration-fast.

Touch

Send is 44 × 44px (--control-height-md); Try again extends to 44px on coarse pointers.

Content

  • Placeholder names the conversation: "Message Sunrise 5K Crew".
  • Times: "8:42 AM". Day separators: "Today", "Yesterday", then "Mon, Apr 13".
  • Failure: "Not sent. Try again", never an error code.
