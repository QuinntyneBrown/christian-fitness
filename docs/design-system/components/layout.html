Layout primitives

Layout primitives place everything else: a centred container, a two-column split, grids, stacks and clusters.

WCAG 2.2 AAStatus: stableCSS only

Overview

  • Container (.container): centres content at --layout-container-max with 16px, then 24px, side margins.
  • Split (.split + a page modifier): one column on phones, main and aside from 1024px (home, event detail, profile, services, dashboard).
  • Console splits: --builder (work, then a 20rem side column: newsletter), --picker (a 17.5rem list of records, then the chosen one: series), --picker-wide (18.75rem, with --picker: listing suggestions), --pick (a 21.25rem form, then the result: Community Pick) and --inbox (a 21.25rem list, then the open item: feedback). See Tables and lists.
  • Grid (.grid, .grid--cards): the column grid, and an auto-fill card grid.
  • Stack (.stack, --sm, --lg, .stack-5, .aside-stack): vertical rhythm. .aside-stack is 40px between panels; --tight 32px (listing profile), --snug 16px (the newsletter's send column, where the buttons belong to the card above).
  • Cluster (.cluster): a wrapping row with an 8px gap for chips, buttons and meta.
  • Page shells: the whole-screen layouts for signed-out pages. .auth (AuthLayout): a brand column and a form column (Join and the password screens). .signin (the sign-in card): a header with the lockup over one centred card on the canvas (member Sign in). .staff (StaffLayout): one centred card on the chrome colour (staff sign in).

See the Layout foundation for breakpoints, columns and gutters.

Anatomy

  1. MainThe page's primary column; min-width: 0 so long content does not overflow.
  2. AsideSecondary panels; below the main column on phones.

Sizes

Stack gaps come from --space-2, --space-4 and --space-8; split gap --space-10; grid gutter --layout-gutter.

States

Layout primitives are not interactive and have no states.

Responsive behaviour

  • Mobile first: every split is one column until --layout-breakpoint-lg (1024px).
  • Console splits keep their gap at every width (32px for builder, picker and pick; 24px and a 24px top margin for picker-wide and inbox); their fixed first or last column only appears from 1024px. Below it the list comes first, so on a phone the picker, form or inbox list sits above the record.
  • Container margins grow from 16px to 24px at 640px.
  • .signin is a column at every width: the header gains side padding at 640px, and the card is top-aligned on phones (so the keyboard does not hide the form) and centred vertically from 640px; the card's padding grows from 28px to 40px at 640px. .auth adds its brand column at 1024px.
  • .grid--cards adds columns as space allows, with no breakpoints.
  • Children of splits and stacks set min-width: 0 so tables and long words scroll or wrap inside them.

Theming

Primitives carry no colour. A stack's gap can be set per use with --stack-gap.

Accessibility

Role and pattern

Layout never reorders content visually away from DOM order: the aside follows the main column on phones and sits to its right on desktop, matching reading and tab order.

Keyboard

KeyAction
TabFollows DOM order, which matches the visual order.

Focus

Not applicable; children own focus.

Labelling

Use landmarks (<main>, <aside aria-label>) on the elements, not the primitives. Each page shell holds one <main id="main"> and the card's <h1>; the sign-in header carries the lockup link only.

Contrast

Motion

None.

Touch

Cluster and stack gaps keep adjacent targets at least 8px apart.

Content

Layout primitives hold no copy of their own.
