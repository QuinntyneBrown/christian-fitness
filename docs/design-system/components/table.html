Component · Data display

Table

Tables let staff compare many members or events at once. They scroll sideways inside their own frame so the page never does.

WCAG 2.2 AAStatus: stableNative <table>Admin console

Overview

Use a table in the admin console when people compare rows across the same columns: members by church, join date and status; events by date, registrations and status. Use a list when each item is read on its own (the member app's event rows and conversations), and a description list for the facts of one thing.

  • Standard (.table) holds four or five short columns; the events table is the reference.
  • Wider (.table--wider) gives a person column with avatar, name and e-mail room to breathe; the members table uses it.
  • Row action is a .row-link button in the last, right-aligned column, with the row's name added for screen readers. Two actions sit in a .row-actions group: the quieter one (.row-link--quiet, muted) first, the main one last (admin events: "Make it a pick", "Edit").
  • Title link (.row-title): when the row opens a page of its own (a story in the editor), its name is the link, semibold and underlined on hover; the cell is .table__wrap, capped at 22.5rem so long headlines wrap instead of widening the table.

The member app has no tables: on a phone, a table of five columns is a sideways scroll, so member-facing data is a list instead.

Anatomy

  1. Wrapper.table-wrap: surface card, --radius-xl, hairline inset border, overflow-x: auto.
  2. Header row14px semibold muted labels with scope="col"; a hairline below.
  3. Primary cell.table__strong name with a .table__sub second line (place or e-mail).
  4. Status cellA status badge; its word carries the state, not its colour.
  5. Action cell.table__end with a .row-link; the header is visually hidden "Actions".

Sizes

One density. Header cells are 12px × 20px padding (--space-3 / --space-5), body cells 16px × 20px (--space-4 / --space-5). Width is set by the minimum: --layout-table-min for standard and --layout-table-min-wide (45rem) for .table--wide and .table--wider; below that the wrapper scrolls.

  • Loading keeps the header and draws skeleton rows (admin events and members loading).
  • Empty ("No events yet") and no results ("No members match…") swap the table for an empty state with one next step.
  • Error replaces the table with an inline error and "Try again"; stale rows are never shown as current.
  • There is no selected-row state: bulk actions are not part of the console.
  • Title link states: .row-title underlines on hover and takes the shared focus ring; it has no data-state="hover" hook.

Responsive behaviour

  • The table keeps its minimum width (--layout-table-min, or 45rem wide) and the wrapper scrolls sideways below it, so the page body never scrolls horizontally.
  • The wrapper is a keyboard-scrollable region in product code: give it tabindex="0", role="region" and the caption's name so keyboard users can scroll it.
  • Dates and counts use .table__nowrap so "Apr 18 · 6:45 AM" never breaks mid-value; names and places wrap.
  • From --layout-breakpoint-lg the admin shell's sidebar is beside the table and every column fits at 1280px.

Theming

The wrapper reads --color-bg-surface and --color-border-default; header text --color-fg-muted; row rules --color-border-default. In the dark theme those map to the dark surface and border, so the table needs no overrides. Status badges and row links bring their own tokens.

Accessibility

Role and pattern

A native data table: <caption> (visually hidden when the page heading already names it), <th scope="col"> for headers. Never use a table for layout, and never rebuild one from divs with role="grid"; no cell is editable inline, editing opens a drawer.

Keyboard

KeyAction
TabMoves between row actions only; cells are not focusable.
Enter, SpaceActivates the focused row action ("Edit Easter Sunrise 5K").
← / →Scroll the wrapper when it has focus and the table overflows.

Focus

Row actions show the shared 2px --color-focus-ring. The scroll wrapper, when focusable, shows the same ring around the card.

Labelling

Each row action appends the row's name in a .visually-hidden span so a list of "Edit" links is unambiguous. The action column's header is "Actions", visually hidden. Avatars are decorative (aria-hidden) because the name is beside them.

Motion

None. Rows do not animate in; skeletons pulse only when motion is allowed.

Touch

Row links sit in a 16px-padded cell and extend to 44 × 44px on coarse pointers. Sideways scrolling works by swipe inside the wrapper.

Content

  • Header labels are nouns in sentence case: "Member", "Joined", "Registered".
  • Dates as "Jan 12, 2026"; event times as "Apr 18 · 6:45 AM". Counts as numerals, capacity as "142 / 200".
  • Missing optional data reads "Not shared" in muted text, never a dash alone; church and faith details are optional.
  • Row actions are one verb: "Edit", "Review"; a secondary action may be a short phrase: "Make it a pick".
  • Story times are relative where recent ("Today, 7:12 AM", "Submitted 1 hour ago") and dated when scheduled ("Sat Apr 18, 6:00 AM").
