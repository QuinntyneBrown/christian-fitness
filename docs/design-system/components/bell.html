Bell

The bell sits in the member top bar before the profile button and says how many notifications are unread.

WCAG 2.2 AAStatus: new<a aria-label>Member app: every signed-in screen

Overview

The bell links to the Notifications screen (/notifications) from every member screen (ADR 0068, ADR 0083). It carries the unread count of the member's notifications:

  • None: nothing unread, or the count is unknown because the list failed to load: the icon alone.
  • Count (.bell__count): one to nine unread, the number in a small bordeaux pill over the icon.
  • 9+: more than nine unread; the accessible name still says the exact number.

It is not a count badge on a navigation link: it has no text of its own, so the number lives in its accessible name. Chat messages are not notifications; they stay as the unread count on Messages.

Anatomy

  1. IconThe 20px bell icon, aria-hidden, muted until hovered or current.
  2. Count.bell__count: 12px bold, white on --color-accent, aria-hidden; the name carries the number.

Sizes

One size: a 44 × 44 px (2.75rem) circle, the minimum touch target, at every viewport.

States

The bell is a link: hover is forced with data-state="hover", focus with data-state="focus", and on the Notifications screen it is aria-current="page".

Both themes

29+
29+
  • While the Notifications screen loads, the bell keeps the count it had (notifications loading).
  • A pushed notification raises the count at once, on any member screen.

Responsive behaviour

The same at every width: in the app header between the navigation and the profile button; on phones, where the navigation moves to the tab bar, it stays in the header.

Theming

Icon --color-fg-muted, hover --color-fg-default on --color-bg-subtle; current --color-fg-accent on --color-accent-subtle; count --color-fg-on-accent on --color-accent. All follow the theme.

Accessibility

Role and pattern

A plain link with an aria-label: "Notifications" with nothing unread, "Notifications, 12 unread" otherwise. The pill is aria-hidden so the number is not read twice and "9+" is never read.

Keyboard

The shared 2px ring around the circle.

The name carries the exact number, so neither the colour nor the pill is the only carrier of "unread".
