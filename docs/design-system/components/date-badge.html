Date badge

Date badges show month and day at a glance, so people find Saturday's run before they read a word.

WCAG 2.2 AAStatus: stableDecorative; the date is also in text

Overview

  • Date badge (.date-badge): a white tile pinned to the top left of an event card image.
  • Date tile (.date-tile): a solid bordeaux tile in the landing hero's floating card.
  • Date column (.event-row__date): the untiled month and day at the start of an event row and dashboard fill row.

All three are visual shortcuts: the full date is always in text nearby, often visually hidden.

Anatomy

  1. Month12px uppercase, semibold (tile) or bold (badge), three letters.
  2. DayBarlow Condensed 24px semibold, line-height 1.

Sizes

Badge --size-date-badge wide; tile and row column --size-date-col; the large event row widens the column to --size-date-col-lg with a 30px day.

States

Date badges are not interactive: no hover, focus, active or disabled of their own. They follow the card or row that holds them. The only state is loading.

  • Loading uses .skeleton--date of the same size.
  • Past events are not shown on member surfaces, so there is no past state.

Responsive behaviour

Fixed size at every width; it never wraps or scales with the card.

Theming

Badge: --color-bg-surface with an accent month (--color-fg-accent). Tile: --color-accent with --color-fg-on-accent. In the dark theme the badge becomes the dark surface, still legible over photos because it is opaque.

Accessibility

Role and pattern

Decorative: aria-hidden="true" on the badge, with the full date in text in the card ("Apr 18, Sat 6:45 AM"), so screen readers hear "Apr 18" once, not "Apr" "18".

Content

  • Month as three letters ("Apr"), uppercased by CSS so screen readers that see it read a word, not letters.
  • Day without a leading zero ("8", not "08").
