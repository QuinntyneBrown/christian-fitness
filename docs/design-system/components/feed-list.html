Component · Data display

Feed list

The feed list offers every RSS feed with its address, how often it posts, a Copy URL button and a way to open it in a reader.

Overview

The RSS section (.rss) closes the Subscribe page for readers who would rather not give an email address: a title with the RSS mark, one paragraph, and the feed list.

  • All stories (.feed--all) comes first on a blush fill: it is what most readers want.
  • Then one feed per section (Events, Training, Nutrition, Faith & Body, Community), each with its posting rate ("~6 a week").
  • Each row offers Copy URL, the universal way into any reader, and Open in Feedly, a one-click shortcut.

Use it only for feeds. A list of things to pick belongs in a list; a list of settings in preference rows.

Anatomy

  1. Name.feed__name, semibold.
  2. Rate.feed__count, muted 14px: "~20 a week".
  3. Address.feed__url in the mono font, one line, truncated with an ellipsis.
  4. Copy URLSecondary small button, fixed 7rem so "Copied" does not shift the row.
  5. Open in FeedlyNeutral small button; opens a new tab.

  • "Copied" reverts to "Copy URL" after about two seconds; the status message stays for screen readers.
  • If the clipboard is refused, the address is already visible and selectable: no error is shown.

Responsive behaviour

  • Phones: each row stacks, name and address above the two buttons.
  • From 640px: one row, text growing and buttons at the end; the address truncates instead of wrapping.
  • From 1024px: the RSS section is two columns, the title and text (1fr) beside the list (2fr).

Theming

The list is --color-bg-surface with hairline --color-border-default rules, on the section's --color-bg-canvas. All stories fills --color-accent-subtle. Rate and address read --color-fg-muted; the RSS mark --color-fg-accent.

Accessibility

Role and pattern

A <ul> of feeds with native buttons and links. Each button's name says which feed through visually hidden text: "Copy URL of the Events feed", "Open in Feedly the Events feed (opens in a new tab)". The copy result is a polite live region.

Keyboard

KeyAction
TabCopy URL, then Open in Feedly, feed by feed.
Enter / SpaceCopies the address.
EnterOpens Feedly in a new tab.

Focus

The shared ring on each button; focus stays on Copy URL after copying.

Labelling

Visible text stays short; the hidden suffix makes every name unique so a list of buttons is not twelve identical "Copy URL"s. The new-tab warning is in the name.

Contrast

Name
Rate, address
Rate on All stories
RSS mark
Section text

Motion

None beyond the buttons' colour transition.

Touch

Small buttons are 36px tall with an 8px gap; on phones they sit below the text, away from it.

Content

  • Feed names match the sections exactly: "All stories", "Events", "Faith & Body".
  • Rates are approximate and weekly: "~4 a week".
  • Show the full address, starting https://; never shorten it.
  • Buttons: "Copy URL" → "Copied"; "Open in Feedly".
