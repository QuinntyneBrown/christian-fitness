File field

A file field lets people choose one file from their device, such as an event's image, and shows what they chose.

WCAG 2.2 AAStatus: stableNative <input type="file">, hidden behind a button

Overview

Use a file field when the answer is a file. For text use a text field. It sits in the same form field layout as every input: a label, the control, a hint and an error.

  • Empty: "Choose image" and "No image chosen".
  • Chosen: the file's name and a Remove button.
  • Invalid: the error replaces the hint and says what is allowed.

Anatomy

  1. Label14px semibold; names the file, with "(optional)" when it may be left out.
  2. Choose buttonA secondary small button that opens the system file picker; the native input stays hidden.
  3. Name and RemoveThe chosen file's name, wrapped when long, and a ghost Remove button; before a choice, the muted "No image chosen".
  4. Hint or errorLinked to the button with aria-describedby; the error replaces the hint.

Sizes

One size: the choose and Remove buttons are the small button, 36px tall with a 44px touch target. The row wraps under a long file name.

  • Replace: choosing again replaces the file; Remove clears it.
  • Busy: while a file uploads, the button reads "Uploading…" and is disabled.

Responsive behaviour

  • Fills its column; the row wraps so the file name sits under the buttons on a phone.

Theming

Uses the button and field tokens; no tokens of its own.

Accessibility

Role and pattern

A visible label, a real button that opens the picker (the hidden input is not focusable, so keyboard and touch use the button), and the hint or error linked with aria-describedby. The chosen name is plain text beside the button; Remove names the file kind for screen readers.

Keyboard

KeyAction
TabMoves between Choose and Remove.
Enter / SpaceOpens the file picker, or removes the file.

Focus

The buttons' own focus ring.

Labelling

The button is labelled by the field label and its own text: "Image Choose image". An error is announced when it appears with the form's error summary, and is reached with aria-describedby.

Content

  • Name the file: "Image", "Photo".
  • Hints say what is allowed: "JPEG, PNG or WebP, up to 5 MB".
  • Errors say the fix: "Use a JPEG, PNG or WebP image up to 5 MB".
