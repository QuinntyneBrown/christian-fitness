Divider

Dividers are hairlines that separate content without adding weight.

WCAG 2.2 AAStatus: stable<hr> or decorative <span>

Overview

  • Horizontal (.divider): an <hr> between sections.
  • Labelled (.divider--label): a rule with centred text, such as "or" between sign-in methods.
  • Vertical (.divider--vertical, .chip-bar__divider): separates groups in a row, like the event filters from the "going" checkbox.

Prefer spacing first; most mock sections are separated by .block-section or .divided-section, which put the rule on the section. Lists separate items with .list-ruled, not dividers.

Sizes

One weight. Vertical dividers are --size-divider-h tall at minimum.

States

Dividers have no interactive states. The only variation is visibility: the filter bar's vertical divider hides on phones.

Responsive behaviour

Horizontal dividers span their container. Vertical dividers in wrapping rows hide below --layout-breakpoint-sm, since a rule at the start of a line means nothing.

Theming

One token: --color-border-default, themed for dark mode.

Accessibility

Role and pattern

A thematic break is an <hr> (implicit separator role). Purely visual dividers inside a row are aria-hidden spans. A labelled divider has role="separator" and its text.
