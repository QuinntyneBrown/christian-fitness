Accordion

Accordions tuck away answers people only sometimes need, so a page stays short and calm.

WCAG 2.2 AAStatus: stableNative <details>Core component, no mock

Overview

Use an accordion for independent sections people scan by heading, like questions about events or privacy. Don't hide the main content of a page, a single paragraph, or anything someone must read before acting (event safety notes stay visible). For switching views use tabs.

No current screen uses an accordion; it is part of the core set for help and FAQ content.

Anatomy

  1. Summary<summary>, semibold, at least --target-comfortable tall; the whole row toggles.
  2. Indicator16px icon at the end that rotates 180° when open; decorative.
  3. BodyMuted text with 16px bottom padding; hairline rules between items.

Sizes

One size. Summary min-height --target-comfortable, 12px block padding.

States

Open and closed come from the native open attribute. Pointer and focus are forced on the summary with data-state. There is no disabled item: content that cannot be read is not listed.

  • Open rotates the indicator and shows the body; the native element announces expanded or collapsed.
  • Items are independent; opening one does not close others.

Responsive behaviour

Full width at every size; summaries wrap onto more lines rather than truncate.

Theming

Rules read --color-border-default, the summary --color-fg-default and the body --color-fg-muted; all themed.

Accessibility

Role and pattern

Native <details>/<summary>: keyboard, expanded state and find-in-page work without script. If an item needs a heading level, put the heading inside the summary.

Keyboard

KeyAction
TabMoves between summaries.
Enter, SpaceOpens or closes the focused item.

Focus

The shared 2px ring around the summary row.

Labelling

The summary text is the name; the indicator is aria-hidden.

Contrast

Summary
Body

Motion

The indicator rotates over --duration-fast; the body appears without animation. Reduced motion removes the rotation.

Touch

The full-width summary is at least --target-comfortable tall.

Content

  • Summaries are the question or topic in sentence case: "What should I bring to a run?"
  • Answers start with the answer: "No.", "Water, a layer…".
