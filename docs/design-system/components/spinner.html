Spinner

A spinner says "working on it" for a short wait, always next to words that say what is happening.

WCAG 2.2 AAStatus: stable.spinner · .icon--spin

Overview

Two forms:

  • Busy icon (.icon--spin on the loader icon) inside a busy button: "Signing in…", "Sending…". This is the form the mocks use.
  • Spinner (.spinner): a ring with a label for a small region that is refreshing, such as a retried section or loading older messages.

Use a skeleton when a page or list is loading for the first time and its layout is known; use a progress bar when the wait is long and measurable. Never cover a whole page with a spinner.

Anatomy

  1. RingA 2px track (--color-border-default) with an accent arc, rotating; aria-hidden.
  2. Label14px muted text saying what is loading; visible, or visually hidden when context makes it obvious.

States

A spinner has one state: spinning. Under reduced motion it stops and shows a half-filled ring; the label keeps the meaning.

Both themes

Refreshing…
Refreshing…
  • Show a spinner only after about 300ms, so fast responses don't flash.
  • If the wait passes about 10 seconds, replace it with words ("Still working…") or an error with a retry.

Responsive behaviour

Same at every width. A region spinner centres in the region it replaces.

Theming

The arc reads --color-accent, the track --color-border-default, the label --color-fg-muted. In a button the icon inherits the label colour.

Accessibility

Role and pattern

The spinning ring is decorative. The busy region carries aria-busy="true" and the label sits in a polite live region (the mocks wrap loading regions in aria-live="polite" with a visually hidden "Loading events"). A busy button sets aria-busy and keeps a visible label.

Keyboard

KeyAction
TabNot focusable; a busy button stays in the tab order but ignores presses.

Focus

{'na': 'Spinners are not interactive; focus stays where it was.'}

Labelling

Always a label: visible text or .visually-hidden. Never a bare animated ring.

Motion

Rotates once per --duration-spin, linear. prefers-reduced-motion stops the rotation for both the ring and .icon--spin.

Touch

{'na': 'Not interactive.'}

Content

  • Present participle with an ellipsis character: "Sending…", "Refreshing…", "Loading older messages…".
  • Name the thing when it helps: "Loading older messages…" beats "Loading…".
