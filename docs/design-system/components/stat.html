Component · Data display

Stat

Stats show the numbers staff watch: how many members, how many registrations, how full each event is.

WCAG 2.2 AAStatus: stableAdmin dashboard<dl> and <meter>

Overview

  • Stat hero (.stat-hero): one headline number on a bordeaux panel, with a label and a change line. The dashboard's member count.
  • Stat tile (.stat in a .stat-grid): smaller figures in a two-column description list.
  • Fill meter (.fill in a .fill-list): registrations against capacity per event, as numbers and a native <meter>.

Use a progress bar for a task that finishes; a fill meter measures a quantity in a range.

Anatomy

  1. Label14px semibold --color-fg-on-brand-highlight with a 16px icon.
  2. ValueBarlow Condensed at --font-size-6xl, line-height 1, thousands separator.
  3. Sub lineChange over a named period in --color-fg-on-brand-muted.

Sizes

One size each. The hero value is --font-size-6xl, tile values --font-size-3xl, the meter --size-meter tall.

States

Stats are read-only: no hover, focus, active or disabled. Their states are loading, empty (no events yet) and nearly full.

  • Nearly full (90% and over) makes the percentage accent and semibold; the number says it too.
  • Empty: with no upcoming events the fill list becomes an empty state ("No upcoming events") with "New event".
  • Partial: a figure that failed to load shows an inline retry in its place; the rest still render (dashboard partial).

Responsive behaviour

  • The tile grid is two columns at every width; the hero spans the column.
  • Fill rows put the date and name on one line and the meter full width beneath.

Theming

The hero reads --color-bg-brand with --color-fg-on-brand, --color-fg-on-brand-highlight and --color-fg-on-brand-muted. Tiles are surface cards. The meter track is --color-border-default and its value --color-accent.

Accessibility

Role and pattern

Tiles are a <dl>; the hero is text in a section with a heading. Fill uses a native <meter> with min, max, value and an aria-label naming the event and both numbers.

Keyboard

KeyAction
TabSkips stats; they are not focusable.

Focus

None.

Labelling

Visible numbers come first; the meter repeats them in words ("Easter Sunrise 5K: 142 of 200 registered"), so the bar is never the only carrier.

Content

  • Labels name the measure and period: "Registrations, April".
  • Numbers use separators ("2,431"); changes are signed ("+86 joined in April").
  • Percentages are whole numbers.
