Textarea

A textarea takes longer answers in people's own words: an About, a message to a professional, an event description.

WCAG 2.2 AAStatus: stableNative <textarea>

Overview

Use a textarea when the answer may run past one line. For one line use a text field. Like every input it sits in a form field.

  • Plain: event description, credentials.
  • With counter: the hint carries the remaining characters ("160 characters left") and is announced politely.
  • One per line: Goals this year, with the hint "One per line".

Anatomy

  1. Label14px semibold, tied with for/id.
  2. Text areaSame border, radius and padding as the text field; rows sets the starting height; no resize handle.
  3. Hint or counterLinked with aria-describedby; replaced by the error when invalid.

Sizes

Height is set with rows: 3 for short bios and messages, 4 by default, 6 for event descriptions. Width fills the column.

States

States follow the text field. Hover in documentation shows the native hover only, because .textarea[data-state="hover"] is not defined.

  • Counter: update the hint text as people type; when the limit passes, switch to an error ("12 characters over") rather than truncating.
  • Read-only while a dialog saves.

Responsive behaviour

  • Fills its column; in a two-column layout a textarea spans both columns.
  • In a phone bottom-sheet dialog, keep rows at 3 so the footer stays visible above the keyboard.

Theming

Shares the field component tokens (--field-border, --field-ring, --field-bg-readonly) with text field and select.

Accessibility

Role and pattern

Native <textarea> with a visible label. The counter lives in the hint referenced by aria-describedby; announce changes with a separate polite live region updated after typing pauses, not every key.

Keyboard

KeyAction
TabMoves to the next field (Tab is not captured).
EnterInserts a new line; it does not submit.

Focus

Accent border plus 2px --color-accent-ring halo.

Labelling

Visible label, hint and error via aria-describedby, aria-invalid when invalid. Use maxlength only with a visible counter.

Content

  • Label the topic: "About", "Message", "Description".
  • Hints set expectations: "A sentence or two", "One per line".
  • Counters count down: "160 characters left".
