Tabs

Tabs switch between filtered views of one list, like published and draft events, and show how many are in each.

Overview

Tabs sit under an admin page head and filter the table below it. Each tab is a link to a URL for that filter, so a filtered view can be bookmarked, shared and reached with Back. The current tab has a bordeaux underline and aria-current="page".

  • Use tabs for two to five mutually exclusive filters of the same list: All, Published, Draft.
  • Add counts (.tabs__count) when the numbers help someone decide where to look.
  • Use filter chips when filters combine, and the sidebar for separate sections.
  • These are navigation tabs, not an ARIA tablist; there are no in-page panels.

Anatomy

  1. Tab label15px semibold, muted until current; the link's name.
  2. Count.tabs__count, muted numeral after the label, part of the name ("Published 4").
  3. Current indicator2px --color-accent underline, overlapping the rule.
  4. RuleHairline --color-border-default across the full width.

Sizes

One size: 15px labels, 24px apart, 12px above the underline.

States

Tabs are links. Current is aria-current="page", shown by the underline and a darker label, so colour is not the only signal.

Both themes

All 5Published 4Draft 1
All 5Published 4Draft 1
  • Hover darkens the label to --color-fg-default; not forced here because the stylesheet has no data-state="hover" hook for tabs.
  • While the table loads, tabs stay usable and the counts stay put; the table shows a skeleton.
  • A tab with a zero count still shows ("Draft 0") so the set never jumps.

Responsive behaviour

  • The row scrolls sideways (scrollbar hidden) when it does not fit; tabs never wrap or truncate.
  • Keep the current tab visible: scroll it into view on load.

Theming

Reads --color-fg-muted, --color-fg-default, --color-accent and --color-border-default; dark theme swaps them through the semantic tier.

Accessibility

Role and pattern

A <nav aria-label="Filter events"> of links with aria-current="page". Because each tab loads a URL, the APG tablist pattern (arrow keys, panels) does not apply.

Keyboard

KeyAction
Tab / Shift + TabMoves between tabs.
EnterOpens that filter.

Focus

Shared 2px --color-focus-ring at 2px offset.

Labelling

The nav names what is filtered ("Filter members"). The count is plain text inside the link so it is read with the label.

Motion

Colour transitions over --duration-fast. The underline does not slide.

Touch

Tabs are 15px text with 12px below; the hit area extends to 44px tall on coarse pointers, and tabs sit 24px apart.

Content

  • One or two words, sentence case, matching the status names in the table (Published, Draft, Flagged).
  • Put All first.
  • Counts are numerals without brackets.
