Avatar

Avatars put a face or initials beside a name, so people recognise each other across events, chats and the admin console.

WCAG 2.2 AAStatus: stable<span> or <img>Decorative

Overview

Use an avatar next to a person's or group's name. It is always decorative: the name beside it carries the meaning, so the avatar is aria-hidden (initials) or has empty alt (photo).

  • Initials (default): accent-subtle circle with one or two display-font letters.
  • Photo: an <img class="avatar">, used for vetted professionals.
  • Group (.avatar--group): a rounded square in inverse colours for event group chats ("5K").
  • Solid (.avatar--solid): bordeaux fill for the signed-in person's own avatar.
  • Stack (.avatar-stack): overlapping small avatars with a "Michael, Danielle and 140 others" label.

Anatomy

  1. ContainerCircle (--radius-full) or rounded square for groups and square photos; --color-accent-subtle fill.
  2. InitialsBarlow Condensed semibold at 36% of the size, --color-fg-accent; at most two letters.

States

Avatars are not interactive, so they have no pointer, focus or disabled state. When one sits in a link or button (the header's profile button) the control owns the state. The only avatar states are photo, initials fallback and loading.

  • Fallback: a photo that fails to load is replaced by initials; never a broken image icon.
  • Loading uses a round skeleton of the same size.

Responsive behaviour

  • Sizes do not change with the viewport; the profile hero uses 2xl at every width.
  • Stacks show at most five avatars; the label carries the total.

Theming

Initials read --color-accent-subtle / --color-fg-accent; group --color-bg-inverse / --color-fg-inverse; solid --color-accent / --color-fg-on-accent. The stack's separating ring is --color-bg-surface, so it matches the card in either theme.

Accessibility

Role and pattern

Decorative: aria-hidden="true" on initials, alt="" on photos, because the person's name is always next to it. Where no name is visible (the header's profile button), the control has the label ("Your profile").

Keyboard

KeyAction
TabSkips avatars; they are never focusable on their own.

Focus

None on the avatar.

Labelling

The adjacent name labels the person. A stack's .avatar-stack__label is real text, so the count is read.

Content

  • Initials: first letter of first and last name, uppercase ("GT"). Group chats use the event's short code ("5K").
  • Stack labels name two people then count: "Michael, Danielle and 140 others".
