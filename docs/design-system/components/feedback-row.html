Feedback row

The feedback inbox lists every note from members, newest first; the chosen one opens beside it with who sent it, from where, and a reply box.

Overview

Members send ideas, bug reports, corrections and thanks from Send feedback and from a story's "Send a correction". Staff read and answer them in the inbox:

  • Feedback row (.feedback-row in a .feedback-list): a link with the kind's icon, who sent it (bold while New), when, and two lines of the note. The open one has aria-current="page". --empty is the row that says "Nothing here." when a filter has nothing.
  • Feedback detail (.feedback-detail): the kind tag (.kind-tag), status and time; the note in full; facts (from, sent from, device); for a correction, a link to the story (.feedback__link); then the reply and Mark resolved or Reopen.
  • You said, we did (.said): on the member's Send feedback page, changes that began as feedback.

The inbox is the list-and-detail split described in Tables and lists. Member conversations use the list and message components instead.

Anatomy

  1. Kind icon.feedback-row__icon: bug, pen, lightbulb or heart; accent when open.
  2. From__from: semibold; bold (--new) while the note is New.
  3. When__when: 12px muted, pushed to the end.
  4. Open rowaria-current="page": --color-accent-subtle fill.
  5. Text__text: two lines, clamped; kind and status follow in visually hidden text.

Sizes

One size. Rows: 16px padding, text 14px clamped to two lines. The list column is 21.25rem from 1024px. The detail is a padded card; its note is 20px.

States

Rows are links: hover is forced with data-state="hover", focus with data-state="focus", open with aria-current="page". New is a content state (bold name, "New" in hidden text and on the detail).

  • Loading: the list and the open note show as skeleton tiles; empty: "No feedback yet" says where notes come from; error: retry in place.
  • The empty row (--empty) is a plain <li>, not a link: it has no hover or focus.
  • Status pills: New (.status--new, highlight), Replied (.status--replied, outline), Resolved (.status--draft); see Badge.

Responsive behaviour

  • Below 1024px the list stacks above the detail; choosing a row loads the detail below (it is a page, so the URL changes).
  • From 1024px: list 21.25rem, detail the rest (.split--inbox).
  • The facts row is one column on phones and three from 640px; name, email and page truncate with an ellipsis.
  • Row names truncate; the time never wraps.

Theming

Rows sit in a list card; hover fills --color-bg-canvas, open fills --color-accent-subtle with the icon in --color-fg-accent. The kind tag is a --color-bg-canvas pill with an accent icon. Facts sit between --color-border-default rules. The said list uses muted italic quotes.

Accessibility

Role and pattern

The list is a <nav aria-label="Feedback"> of links with aria-current="page" on the open one (not a listbox: each row is its own URL). The detail is a <form> with a visually hidden <h2> ("Something’s broken from Michael Chen"); the facts are a <dl>. The reply has a visible label ("Reply to Michael") and a hint joined with aria-describedby.

Keyboard

KeyAction
TabRow to row, then into the detail: story link, reply, Send reply, Mark resolved.
EnterOpens a note; sends the reply from the button.

Focus

The shared ring around the row.

Labelling

A row reads: name, time, the note, then "Something’s broken, New" from hidden text, so kind and status are not carried by the icon or weight alone. Icons are decorative.

Contrast

Name and note
Row text and time
Open row text
Open row muted
Kind tag
New pill

Motion

Row background over --duration-fast; none under reduced motion.

Touch

Rows are full width and at least 72px tall.

Content

  • Kinds: Idea, Something’s broken, Content (a correction), Praise. On the member form: "An idea", "Something’s off", "A correction", "Thanks".
  • Times are relative: "35 min ago", "Yesterday", "2 days ago".
  • Reply hints tell staff what a good answer says: "Let them know we can reproduce it and when to expect a fix".
  • Said: the member's words in quotes, what changed, and the month.
