Drawer

A drawer slides in from the right so staff can create or edit an event or listing without losing their place in the list.

WCAG 2.2 AAStatus: stablerole="dialog" + aria-modalAdmin console

Overview

The drawer is a modal side panel for longer editing tied to a list: the admin event editor and listing editor. The list stays visible (dimmed) on wide screens, so staff keep their bearings.

  • Use a drawer for forms of five or more fields that edit one item in a list.
  • Use a dialog for short tasks and confirmations.
  • Opens through CDK Dialog with a right-side position; never a hand-rolled panel.

Anatomy

  1. Title.drawer__title, "New event" or "Edit event"; names the dialog.
  2. CloseIcon button labelled "Close".
  3. Body.drawer__body, the form; scrolls.
  4. Footer.drawer__foot: Save draft and Publish, each .btn--grow.

Sizes

One size: up to --layout-dialog-max (512px) wide, full height; full width on phones.

States

Open, busy, invalid and failed, like the dialog. Controls keep their own states.

VariantDefaultHoverFocusActive
Close

Busy

New event

Publishing: the primary is busy; fields stay readable.

Both themes

New event

New event

  • Invalid: an error summary at the top of the body links to each field.
  • Failed: a form alert at the top; nothing is lost.
  • On success the drawer closes and an admin toast confirms ("Event published").

Responsive behaviour

  • Below 512px the drawer fills the width.
  • Above, it is 512px against the right edge; the dimmed list shows to the left.
  • Two-column field rows (.field-grid) stack on phones.

Theming

Reads --color-bg-surface-raised, --shadow-4 and --color-bg-backdrop; dark theme swaps them.

Accessibility

Role and pattern

Same as a modal dialog: role="dialog", aria-modal="true", aria-labelledby the title, the page behind inert.

Keyboard

KeyAction
Tab / Shift + TabCycles within the drawer.
EscCloses and returns focus to the trigger.

Focus

Focus goes to the first field on open and back to the trigger ("New event" or the row's Edit) on close.

Labelling

The title names it; Close is labelled.

Contrast

Title on drawer
Focus ring on drawer

Motion

Slides in from the right over --duration-slow; under reduced motion it appears without sliding.

Touch

Close 44 × 44px; footer buttons 48px tall.

Content

  • Title: "New event", "Edit event", "Edit listing".
  • Footer: "Save draft" and "Publish" (or "Save changes").
