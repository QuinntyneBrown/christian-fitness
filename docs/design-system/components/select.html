Select

A select picks one option from a list too long to show as radios: an event category, a session type, a role.

WCAG 2.2 AAStatus: stableNative <select>

Overview

Use a select for one choice from five or more known options. For two to four options that people should compare, use a radio group, which shows every option at once. For actions, use a menu. The select is always native, so phones show their own picker.

  • Default: one option preselected when there is a sensible default.
  • With prompt: a first option "Choose a category" when there is no default, which fails validation if left.

Anatomy

  1. Label14px semibold, tied with for/id.
  2. FieldSame border, radius and padding as the text field; shows the selected option.
  3. IndicatorThe platform's native arrow; not restyled.

Variants

Category in the event editor.

<div class="field"><label class="field__label" for="sel-v1">Category</label><select class="select" id="sel-v1"><option>Run</option><option>Workout</option><option>Basketball</option><option>Mobility</option><option>Workshop</option><option selected>Retreat</option></select></div>

Sizes

One size, matching the text field: 16px text, about 50px tall.

States

The select shares the text-field states except read-only, which native selects do not support (use disabled plus a hidden input, or show the value as text).

VariantDefaultHoverFocusDisabledInvalid
Select

Both themes

  • Hover in documentation is native only: .select[data-state="hover"] is not defined.
  • Open is drawn by the platform and cannot be styled.

Responsive behaviour

Fills its column. On phones the native wheel or sheet appears; nothing to adapt.

Theming

Shares the field tokens. color-scheme on the theme root makes the native dropdown follow light and dark.

Accessibility

Role and pattern

Native <select> with a visible label. Never a custom listbox when a native select will do.

Keyboard

KeyAction
↑ / ↓Changes the option (opens the list on some platforms).
Space, Alt + ↓Opens the list.
TypingJumps to the option starting with those letters.
EscCloses the list without changing.

Focus

Accent border plus 2px --color-accent-ring.

Labelling

Visible label; error via aria-describedby and aria-invalid. Do not change the page on change; let people confirm with the form's button.

Value on surface

Motion

Border transition only.

Touch

About 50px tall; the platform picker handles the rest.

Content

  • Options in sentence case, in a meaningful order (by frequency or the order people think of them), not alphabetical by default.
  • The prompt option starts with a verb: "Choose a category".
