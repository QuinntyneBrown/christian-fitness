Follow button

The follow button follows or unfollows a directory listing in one tap, so its new dates reach the member first.

WCAG 2.2 AAStatus: new<button aria-pressed>Member app: Directory

Overview

Use the follow button wherever a listing (an organization, person, instructor or church ministry) can be followed: on each listing row in the Directory and in the head of a listing's profile. It acts at once in both directions, with no confirmation; if the request fails, the button goes back and a toast says so.

  • Row (.follow): a fixed-width outlined pill at the end of a directory row; "Follow" always, tinted with a check when pressed.
  • Large (.follow--lg): the profile's main action, beside Message. Not followed, it is the bordeaux primary; followed, it turns tinted like the row button.

It is a toggle, not a button variant and not a chip: one listing, on or off, saved immediately.

Anatomy

  1. Check (followed only)16px check icon, aria-hidden; the shape, not just the tint, says it is on.
  2. Label"Follow" in every state, 14px semibold, plus the listing's name in visually hidden text.
  3. ContainerA 108px (6.75rem) pill, 36px tall (--control-height-sm), so the pressed and unpressed buttons take the same space and the row does not jump.

Sizes

  • Row (.follow): 108px wide, at least 36px tall, 14px label.
  • Large (.follow--lg): at least 44px (--control-height-md), 16px label, 24px side padding; it grows to share the row with Message on phones and takes its own width from 768px.

States

On and off are the real aria-pressed attribute; hover and focus are forced here with data-state (live: :hover, :focus-visible). Hover darkens the row button's outline and the large button's fill. A followed button's hover is real :hover only: forcing it with data-state on the large button would show the unfollowed fill, so that cell is left empty.

Message
  • Failed: the button goes back to where it was and a danger toast names the listing (directory follow-failed). Nothing else on the page changes.
  • Busy: the press flips the button at once and the request runs behind it; until it settles the button carries aria-disabled="true", shows a progress cursor and ignores presses (L2-056 AC8; ADR 0088). It looks as its new state does.
  • Disabled: none. A listing that cannot be followed shows no follow button.

Responsive behaviour

  • Row: fixed width at every breakpoint, at the end of the listing row, never wrapping (white-space: nowrap, flex-shrink: 0).
  • Large: below 768px it grows (flex: 1) to share the profile's action row with Message; from 768px (--layout-breakpoint-md) it sizes to its label.
  • Under (pointer: coarse) an invisible pseudo-element extends the target, but only to --target-min (24px), which the 36px button already exceeds, so in practice it stays 36px tall.

Theming

Off, the row button is transparent with a --color-border-default outline (--color-border-strong on hover) and default text. On, both sizes take --color-accent-subtle and --color-fg-accent (large hover --color-accent-subtle-hover). The large button off is --color-accent with --color-fg-on-accent (hover --color-accent-hover). All switch with the theme.

Accessibility

Role and pattern

A toggle button: native <button> with aria-pressed (APG Button). The label is fixed ("Follow") and never changes while toggling, as the APG asks of a toggle button: aria-pressed carries the state to assistive technology, and the fill plus a check icon carry it visually.

Keyboard

KeyAction
TabMoves to the button (after the row's link).
Enter, SpaceFollows or unfollows.

Focus

The shared ring: 2px --color-focus-ring at 2px offset, following the pill. Focus stays on the button after it flips and after a failure.

Labelling

Every button names its listing in visually hidden text ("Follow Christian Fitness"), since a page has many. The pressed state is announced from aria-pressed; the check icon makes it visible without relying on the tint, and the label never changes.

Motion

Fill, outline and colour change over --duration-fast; instant under reduced motion.

Touch

The large button is 44px tall. The row button is 36px tall and 108px wide; under a coarse pointer an invisible extension takes its target to --target-comfortable (44 × 44 px), as small buttons and chips do (L2-054 AC9).

Content

  • "Follow", nothing else, in both states: no "Unfollow" on hover, no "Subscribe".
  • Always add the listing's name in visually hidden text, so a screen reader hears "Follow Lakeshore Runners Fellowship".
  • The failure toast names the listing and the fix: "We couldn't follow Faith & Footwork" / "Try again in a moment."
