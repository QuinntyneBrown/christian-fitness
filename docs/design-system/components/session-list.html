Session list

The session list shows every date of a series in order: which are done, which is next, which were cancelled, and what each one is about.

Overview

A series' dates are an ordered list: the order is the program. Three blocks share the job:

  • Session row (.session-row in a .list-ruled.session-list): the member's series page. A date tile, "Session 3 · Tue", the topic, and an end slot: "You came", Done or Missed, Details for the next date, a Drop in tick box, or Cancelled.
  • Session meter (.session-meter): one bar per date, a glance at the same list in series rows and series progress.
  • Admin sessions (.admin-sessions of .admin-session): the admin Series screen, where staff cancel or restore a date.

Use a list of event rows for unrelated events, and the series card for the next three dates on a session's own page.

Anatomy

  1. Date tile.session-row__date, 56px column (--size-date-badge): month over a display day; filled accent for the next date, outlined for upcoming, bare and muted for past and cancelled. aria-hidden.
  2. Meta"Session 3 · Tue" with the date in visually hidden text, and "· Next up" on the next one; accent then, muted otherwise.
  3. TopicWhat the session is about; semibold, regular and muted once past, struck through when cancelled.
  4. End.session-row__end: Details (next), "You came" (accent, with a check), Done, Missed or Not recorded, Cancelled, or a Drop in tick box.

Sizes

One size. Member rows are 16px top and bottom with a 56px date tile; admin rows are 16px × 20px and wrap under 12rem of topic. Meter bars are 6px tall in a series row and 8px in series progress.

States

Rows are not links; the state of a session is a modifier (--next, --past, --cancelled) because it changes the whole row, and each state is also said in words in the meta or end slot. Interactive states belong to the controls in the end slot (button, checkbox).

  • Next fills the date tile with --color-accent and adds "Next up" to the meta; cancelled strikes the topic and says "Cancelled": neither relies on colour or the line alone.
  • Cancelling a date opens the Cancel this date? dialog; after it, the row reads Cancelled with Restore and a toast says who was told (admin-series/date-cancelled).

Responsive behaviour

  • Session row: the same three columns at every width (56px tile, flexible body, end slot sized to its content); topics wrap, the end never shrinks.
  • Admin session: number, date, topic and end sit on one line when there is room; the row wraps so the end goes below the topic on narrow panels (flex-wrap, topic basis 12rem).
  • Meter: bars share the width equally; in a series row it is capped at --layout-conversations-width.

Theming

Date tiles read --color-bg-surface with a --color-border-default ring, the next one --color-accent/--color-fg-on-accent. Month, next meta and "You came" are --color-fg-accent; meta, status and past text --color-fg-muted. Admin rows reuse status badges and quiet link buttons (.btn--link-quiet, --color-fg-muted).

Accessibility

Role and pattern

An <ol>: the order is meaningful and screen readers announce "list, 8 items". The date tile is aria-hidden and repeated in the meta's visually hidden text ("Session 3 · Tue, Apr 21 · Next up"). Controls in the end slot name their session in hidden text: "Details of session 3", "Drop in on Sat, Apr 25", "Cancel date: session 4, Tue Apr 28".

Keyboard

KeyAction
TabMoves only between the controls in end slots (Details, Drop in, Cancel date, Restore); rows themselves are not focusable.
SpaceTicks or unticks a Drop in box.
EnterFollows Details; activates Cancel date or Restore.

Focus

The shared ring on each control. After Cancel date's dialog closes, focus returns to the row's Restore button.

Labelling

Row states are announced from text: "Next up", "You came", "Done", "Missed", "Cancelled". The struck-through topic is not the only cue. The meter is aria-hidden; its count ("2 of 7 sessions done") is visually hidden text.

Contrast

Topic
Meta, status, past topic
Month, next meta, You came
Next date tile
Upcoming tile month
Admin row text
Meter bars (decorative)

Motion

None in the rows; the controls use their own transitions.

Touch

Details is a 36px button whose target extends to 44 × 44px on coarse pointers (.session-row .btn--xs); the Drop in label is the target for its box. Admin Cancel date and Restore are 24px link buttons whose target extends to 44 × 44px on coarse pointers.

Content

  • Meta: "Session 3 · Tue"; add "· Next up" to the next one only.
  • Topics say what happens that day, in sentence case: "First 5-minute run", "No class: Victoria Day week".
  • End words: "You came" for the member's own attendance; "Done" when they had not joined; "Missed" when staff recorded that they joined and did not come; "Not recorded" when no attendance is recorded; "Cancelled".
  • Admin dates read "Tue Apr 21"; actions are "Cancel date" and "Restore".
