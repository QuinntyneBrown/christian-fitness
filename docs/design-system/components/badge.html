Badge

Badges label a state or a count in a word or a number: Published, Flagged, 4 unread.

Overview

Use a badge to show something's status or how many new things wait. It never acts; to filter, use a chip.

  • Status (.status): admin rows: Published, Draft (events); Active, Flagged, Suspended (members).
  • Count badge (.count-badge): unread total beside the Messages nav link.
  • Count pill (.count-pill): unread total at the end of a conversation row.
  • Unread dot (.unread-dot): a labelled dot when the exact number does not matter.
  • Going pill (.going-pill): "Going" on an event card's image; see Event card.

Anatomy

  1. ContainerPill (--radius-full), 4px × 10px padding; draft and active add a hairline inset border.
  2. Label12px bold, one word, sentence case.

Sizes

One size: 12px label (--font-size-xs). Counts above 99 read "99+". The dot is --size-dot-lg.

States

Badges are static: no hover, focus, active or disabled. Their variants are their states. A count badge disappears at zero.

Both themes

PublishedDraftActiveFlaggedSuspended1
  • Flagged is the loudest (solid bordeaux) because it needs a decision; Suspended is inverse; Active and Draft are quiet outlines.
  • When the count changes in real time, the region announcing it is polite; the badge itself is not a live region.

Responsive behaviour

  • Badges never wrap (white-space: nowrap) or truncate.
  • On phones the count moves to the tab bar as a .tab-bar__dot.

Theming

Each status pairs a fill and a text token: published --color-accent-subtle/--color-fg-accent, flagged --color-accent/--color-fg-on-accent, suspended --color-bg-inverse/--color-fg-inverse, draft and active --color-bg-canvas with a --color-border-default ring. Generic .status--success, --warning, --danger and --info use the status tokens.

Accessibility

Role and pattern

Plain text in a <span>. Status words are read in place. Numeric badges add an aria-label with the noun ("4 unread"); dots use role="img" and an aria-label.

Keyboard

KeyAction
TabSkips badges; they are not focusable.

Focus

None.

Labelling

A bare "4" means nothing when read; always label counts with what they count.

None; counts update without animation.

Content

  • One word, sentence case: "Published", "Flagged". Not "LIVE" or "OK".
  • Counts are numerals, capped at "99+".
