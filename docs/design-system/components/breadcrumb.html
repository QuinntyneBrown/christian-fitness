Breadcrumb

A breadcrumb shows where a page sits and gives one step back up; on phones it shrinks to the parent.

WCAG 2.2 AAStatus: proposed<nav> + <ol>No mock yet

Overview

Use a breadcrumb on pages two or more levels deep, where the back link alone would lose the trail: an admin listing inside Services, an event inside Events. The last item is the current page with aria-current="page".

  • Use a back link when there is only one level up (the mocks do this today on event detail).
  • .breadcrumb--collapsible shows only "← Parent" below 768px.
  • Never use it as the main navigation or for steps in a process.

Anatomy

  1. Ancestor link14px semibold muted link, 44px tall hit area.
  2. SeparatorA "/" drawn by CSS in --color-fg-subtle, never read aloud.
  3. Current pageLast item, aria-current="page", default colour, no underline.

Sizes

One size: 14px (--font-size-sm).

States

Ancestors are links with hover, focus and active; the current item is a link with aria-current.

  • Hover underlines and darkens the link.
  • The current item keeps no underline on hover.
  • No disabled state: an ancestor you cannot open is left out.

Responsive behaviour

  • Below 768px .breadcrumb--collapsible hides every item but a "← Parent" link.
  • Above, items wrap rather than truncate.

Theming

Reads --color-fg-muted, --color-fg-default and --color-fg-subtle; dark theme swaps them.

Accessibility

Role and pattern

APG Breadcrumb: <nav aria-label="Breadcrumb"> around an ordered list; separators are CSS so they are not announced.

Keyboard

KeyAction
TabMoves through the links.
EnterFollows the link.

Focus

Shared ring with a 2px radius (--radius-xs).

Labelling

The nav is labelled "Breadcrumb". The collapsed parent link reads "Events"; its arrow icon is hidden.

Contrast

Ancestor
Current

Motion

None.

Touch

Every link has a 44px minimum height (--target-min).

Content

  • Use each page's own title, shortened only if the title is a sentence.
  • Do not repeat the current page title as a heading right beside it in a different form.
